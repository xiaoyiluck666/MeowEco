# 决策记录：Paper 26.1.1 构建兼容策略

## 背景
`io.papermc.paper:paper-api:26.1.1.build.14-alpha` 在仓库元数据中要求 `org.gradle.jvm.version = 25`。项目默认子模块仍以 Java 17 为基础编译目标。

## 决策
采用“Paper 模块单独使用 JDK 25 工具链 + 继续输出 Java 17 字节码 + 增加旧版 Paper 二次编译校验”的策略。

## 原因
- 直接维持 JDK 17 toolchain 无法解析 `paper-api:26.1.1.build.14-alpha`。
- 直接把插件产物字节码提升到 25，会无谓降低旧环境兼容性。
- 仅升级编译依赖不能防止后续误用 26.x 新 API，需要自动化守卫。

## 落地方式
- `:meoweco-paper` toolchain 使用 Java 25。
- `:meoweco-paper` 编译仍使用 `options.release = 17`。
- `compileLegacyPaperCompatJava` 使用 `paper-api:1.20.4-R0.1-SNAPSHOT` 重新编译主源码，并挂到 `check`。

## 影响
- 构建 `meoweco-paper` 需要本机或 CI 可用 JDK 25。
- 插件产物仍保持 Java 17 字节码，对旧版已支持环境更安全。
- 后续新增 Paper 专属 API 时，会在 `check` 阶段被尽早发现。
