# MeowEco 26.9.1 更新日志

发布日期：2026-06-29

## 🚀 本次重点

MeowEco `26.9.1` 是一个面向 **Paper 26.1.x / 26.2** 的性能维护版，重点优化 Vault 默认货币余额读取压力。

很多商城、菜单、权限、任务或展示插件会通过 Vault 高频查询玩家余额。本次版本给 Vault 默认货币读取路径增加了一个极短缓存，在保持扣款安全的前提下，减少重复数据库读取，让繁忙服务器的经济交互更轻、更稳。

## ✨ 新增

- ⚡ 新增 Vault 默认货币余额短缓存，降低外部 Vault 插件频繁 `getBalance` / `has` 查询造成的数据库压力。
- 🧾 新增 26.9.1 发布说明，明确说明缓存策略、适用范围和安全边界。
- 🧹 玩家退出时会清理对应 Vault 缓存，减少长期运行服务器中的无效缓存残留。
- 🧪 新增 Paper 26.1.2 稳定 API 兼容编译检查，和现有 26.1.x 最早线、26.2 主编译一起覆盖发布版本范围。

## 🔄 变更

- ☕ 插件版本提升至 `26.9.1`。
- 🔁 Vault、MeowEco API、管理命令、转账兑换、进服建户和富人税等写入路径成功后都会主动清理相关缓存。
- 🧠 玩家级缓存清理会移除该玩家所有 Vault 缓存键，不依赖当前默认货币配置。
- 📦 发布验证覆盖 Paper 26.1.x 最早 API、Paper 26.1.2 稳定 API 和 Paper 26.2 主目标 API。

## 🛠️ 修复与优化

- 🛡️ 缓存只用于 Vault 默认货币读取，不参与扣款、加款或建户写入判断。
- 🔒 Vault 扣款仍然直接走数据库原子更新，余额不足时由数据库最终拒绝，避免因短缓存产生刷钱或误扣风险。
- 🧽 清理 README 行尾空格，同时保留带表情的介绍展示效果。

## 🌟 为什么值得升级

- 🏪 商城、菜单、VIP、奖励领取等插件频繁读余额时，数据库压力更低。
- 📊 余额展示、前置条件检查和菜单刷新更轻量。
- 🔌 Vault 兼容路径更适合高频交互服务器。
- 🛡️ 写入路径仍保持强安全边界，不为了性能牺牲经济数据正确性。

## ⚠️ 升级提醒

- 服务器需要运行在 **Java 25**。
- 当前版本面向 **Paper 26.1.x / 26.2**。
- 升级前建议备份数据库与配置文件，尤其是生产服的经济数据。
- 如果你刚从 26.9.0 升级，本版本不需要额外迁移配置。
