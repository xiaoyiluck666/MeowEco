# MeowEco 26.9.0 更新日志

发布日期：2026-06-29

## 🚀 本次重点

MeowEco `26.9.0` 面向 **Paper 26.1.x / 26.2** 与 **Java 25** 服务器发布。本次更新把插件主构建目标推进到 Paper 26.2，同时保留 26.1.x 兼容编译检查，让想升级新版服务端的服主可以更安心地接入。

这也是一次偏“稳定经营”的版本：金额精度、数据库回归、SQLite 测试、文档介绍和发布产物都做了同步整理，适合多货币、商城、排行榜、富人税和菜单联动玩法继续迭代。

## ✨ 新增

- 🛡️ 新增 Paper 26.2 主 API 支持，当前构建目标为 `paper-api:26.2.build.40-alpha`。
- 🧪 新增更完整的经济回归测试，覆盖转账、兑换、冻结资金、富人税和金额精度策略。
- 🗄️ 新增 SQLite 数据库回归测试，覆盖账户创建、转账、兑换回滚、冻结资金和排行榜排除逻辑。
- 🔍 新增历史余额精度报告能力，可只读扫描旧数据中的超精度金额，帮助服主评估是否需要整理经济数据。

## 🔄 变更

- ☕ 插件版本提升至 `26.9.0`。
- 🧱 当前支持范围更新为 **Paper 26.1.x / 26.2**，服务器运行环境仍要求 **Java 25**。
- 📦 构建链继续保留 Paper 26.1.x 兼容编译检查，避免无意间引入只适用于 26.2 的 API。
- 🔌 调整 Maven 仓库解析，让 Paper 26.2 依赖的 Adventure 5.x 组件从 Maven Central 正常获取。
- 📚 优化 README 与 Wiki 介绍，让服主能更快看懂 MeowEco 适合哪些玩法、能解决什么问题。

## 🛠️ 修复与优化

- 💰 统一命令、API 与 Vault 金额输入的精度处理，减少超长小数导致的余额显示和存储问题。
- 🧾 优化税收、兑换和周期任务结果的金额舍入，让数据库里的经济数据更规整。
- 🧹 清理旧的非 Paper 模块和过时文档表达，项目方向更明确：只维护 Paper 插件。
- ⚙️ 调整本地构建与缓存忽略项，减少生成文件、运行目录和本地依赖对仓库的干扰。

## 🌟 适合升级的服务器

- 🪙 正在做金币、点券、宝石、代币等多货币经济的服务器。
- 🏪 需要和 Vault、PlaceholderAPI、TrMenu 联动的商城 / VIP / 兑换菜单。
- 📊 重视排行榜、余额展示、全服总资产统计的展示型玩法。
- 🧊 需要冻结资金、扣除冻结资金、富人税等经济调控能力的 RPG / 生存服。
- 🛡️ 准备升级到 Paper 26.2，但仍希望保留 Paper 26.1.x 兼容约束的服主。

## ⚠️ 升级提醒

- 服务器需要运行在 **Java 25**。
- 当前版本面向 **Paper 26.1.x / 26.2**。如果你的服务器仍在 Paper / Minecraft `1.21.11` 或更旧版本，不建议直接升级本版本。
- 升级前建议备份数据库与配置文件，尤其是生产服的经济数据。
- 如果使用 MySQL，请先在测试服验证连接参数、字符集和权限配置。
