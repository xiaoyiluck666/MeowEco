# MeowEco 26.8.1 更新日志

发布日期：2026-05-19

## 🚀 本次重点

MeowEco `26.8.1` 面向 **Paper 26.1 / 26.1.1 / 26.1.2** 与 **Java 25** 服务器发布。本次更新重点提升新版 Paper 环境下的可用性，并改善 MySQL 存储的开箱体验。

## ✨ 新增

- 🗄️ MySQL 存储现在随 Paper 插件内置驱动，服主无需再单独安装 MySQL 驱动文件。
- ⚙️ 新增 MySQL 连接池配置，可根据服务器规模调整连接数量、超时和连接生命周期。

## 🔄 变更

- ☕ 插件版本提升至 `26.8.1`。
- 🛡️ 明确支持范围为 `Paper 26.1`、`Paper 26.1.1`、`Paper 26.1.2`，运行环境统一要求 Java 25。
- 🔌 MySQL 默认连接参数升级为 `utf8mb4`，并改善 MySQL 8 常见认证与连接超时场景。
- 📚 更新文档中的版本、Paper 支持范围和 Java 运行环境说明。

## 🛠️ 修复与优化

- 🧹 清理旧文档中关于 Java 17 兼容策略的过时描述，避免升级判断混淆。
- 🛠️ 优化 MySQL 连接稳定性，降低字符集、认证方式和慢网络导致的连接问题。

## ⚠️ 升级提醒

- 服务器需要运行在 **Java 25**。
- 当前版本面向 **Paper 26.1 / 26.1.1 / 26.1.2**。如果你的服务器仍在 Paper / Minecraft `1.21.11` 或更旧版本，不建议直接升级本版本。
- 升级前建议备份数据库与配置文件，尤其是生产服的经济数据。
