# Paper 26.1.1 兼容处理报告

## 目标
让 `meoweco-paper` 支持 `Paper 26.1.1`，并继续保持对旧版已支持 Paper API 的兼容约束。

## 实施内容
- 将 `meoweco-paper` 的编译依赖从 `paper-api:1.20.4-R0.1-SNAPSHOT` 升级为 `paper-api:26.1.1.build.14-alpha`。
- 在根 `build.gradle.kts` 中仅对 `:meoweco-paper` 模块切换到 JDK 25 toolchain，仍保持 `options.release = 17`，避免把插件字节码整体抬高。
- 在 `meoweco-paper/build.gradle.kts` 新增 `compileLegacyPaperCompatJava` 任务，使用 `paper-api:1.20.4-R0.1-SNAPSHOT` 对同一份源码再次编译，防止引入只在 26.x 存在的 API。
- 将兼容编译任务接入 `check`，让后续 CI/本地验证自动覆盖这一约束。
- 将 `plugin.yml` 描述改为不写死特定版本号，避免后续误导。
- 在 `CHANGELOG.md` 追加本次构建兼容变更记录。

## 验证
执行命令：`./gradlew.bat :meoweco-paper:check :meoweco-paper:shadowJar`

结果：成功。

覆盖点：
- `compileJava` 使用 `paper-api:26.1.1.build.14-alpha` 成功编译。
- `compileLegacyPaperCompatJava` 使用 `paper-api:1.20.4-R0.1-SNAPSHOT` 成功编译。
- `shadowJar` 成功产出 Paper 插件构件。

## 结论
当前实现已经满足“支持 `Paper 26.1.1` 并继续兼容旧版 Paper API”的最小可运行闭环。后续若需要更强保证，可再补真实服务器启动烟测。
